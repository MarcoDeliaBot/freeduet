やることが多すぎて、手が足りませんか？

メール、請求書、契約書、食事の予約。FreeDuetは、あなたのパソコンを、担当ひとりにひとつの仕事がある落ち着いた小さなスタジオに変えます。以下の場面は、架空の例を使った説明用のイラストです。

クイックスタート

最初の仕事まで4つのステップ。

お使いのClaudeプランに加え、Docker、Bash、Bunが必要です。WindowsではWSL2で、Linuxでも動作します（CIはLinuxで起動します）。macOSでは試していません。

  1. 01
    コードを入手する

    GitHubからFreeDuetを取得し、設定ファイルのサンプルをコピーします。

  2. 02
    起動スクリプトを実行する

    アプリ、すべてのアシスタント、隔離されたメンバーのブラウザを起動します。Docker、Bash、Bunが必要です（WindowsではWSL2）。

  3. 03
    Claudeプランで一度サインインする

    公式のClaude Codeに、ご自身でサインインしてください。FreeDuetがサインイン情報をコピーしたり転送したりすることはありません。サインイン情報は、Dockerのボリューム内にローカルで残ります。

  4. 04
    localhost:3010を開き、Irisにあいさつする

    身近な小さな仕事を、あなたの言語で1つ書いてください。Irisが適切なメンバーに渡し、必要なところであなたの承認を求めます。

すべてのコマンド · コピーして実行
$ git clone https://github.com/MarcoDeliaBot/freeduet.git$ cd freeduet && cp .env.example .env$ bash scripts/start.sh # アプリ、チーム、ブラウザ$ cd openbot && docker compose exec -it agent-freeduet claude
次に localhost:3010 を開くIrisにあいさつして、最初の小さな仕事を始めてください。

GitHubの完全なロードマップ GitHubで質問・報告

FreeDuetは、業務利用を含めMITライセンスの下で無料かつオープンソースです。お支払いいただくのは、すでにお持ちの月額のAIサブスクリプションです。現在は、公式のClaude Codeアプリを通じたClaudeプランです。トークン単位で購入するAPIキーはありません。エンジンのページで無料または手元のモデルを追加できますが、どれも初期設定ではオフで、これまで実際のやり取りに応答したのはClaudeのログインだけです。

Claudeのサブスクリプションと、パソコンのDocker、Bash、Bunです。開発者はWindowsでWSL2を使って実行し、CIはLinuxで正しく起動します。macOSではまだ試していません。ワンクリックのインストーラーは、進行中の最優先項目です。UbuntuとWindows向けの最初のセットアップスクリプトは、まだまっさらな環境で実行されていません。

アプリ、データベース、各アシスタントの隔離されたブラウザは、あなたのパソコンで動きます。初期設定では、会話はそこに保存されたままです。考えるときのリクエストは、あなたがサインインしたAIサービス（またはエンジンのページで手動で有効にした追加エンジン）に送られます。

調べる、読む、確認する、下書きや短い報告を用意することができます。初期設定では、送信・支払い・署名・予約・削除は、あなたの承認カードで一時停止します。言葉は固定の決まりで照合し、残りは審査用のモデルが、あなたの入力内容と照らして確認します。例外は3つです。あなた自身が入力したアドレスへの、まったく新しいメール。あなたが設定した常時のメールルール（ラベル付け、アーカイブ、既読化、迷惑メールかゴミ箱への移動のみ）。そして、メンバーに対してオンにしたFull access。アシスタントも間違えることがあるので、承認する前に、すべてのカードを読んでください。

はい。チャットでLeoに、必要な仕事に合わせた新しい専門担当の設計を頼むか、メンバーの定義を自分で編集できます。ツールがない場合、Leoはまず出典とライセンスを示し、あなたの「はい」なしには何もインストールしません。

v0.2.2は、パソコンからQRコードで表示されるワンタイムコードを使って、スマートフォンのブラウザとペアリングできます。これは2026年11月16日に、開発者自身のインストールで一度実行されました。ペアリングの解除とスマートフォンからの承認はまだ確認されておらず、自宅のネットワークの外からのリモートアクセスは進行中です。
