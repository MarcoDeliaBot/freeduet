FreeDuet

あなた専用の、AIアシスタントチーム。

FreeDuetは、あなた自身のパソコンで動きます。メールを扱う担当、契約書を読む担当、レストランを予約する担当がいます。必要なことを伝えるだけ。あとはアシスタントが進めます。そして、初期設定では、送信・支払い・削除は、あなたに確認するまで行いません。

GitHubでFreeDuetを入手 しくみを見る
  • 無料のオープンソース
  • APIキーの購入は不要
  • あなたのパソコンで動作

やることが多すぎて、手が足りませんか？

メール、請求書、予約、契約書、先週約束した返信。頭はひとつ、手は二本なのに、やることは山ほどあります。

FreeDuetは、パソコンの中にある小さなオフィスのようなものです。アシスタントはそれぞれ、ひとつの仕事を得意としています。あなたはチームをまとめるIrisに話しかけるだけ。Irisが全員に動いてもらいます。

アシスタントのチームです

チャットボットは、質問に答えてくれる賢い友だちのような存在です。FreeDuetは、全員がしっかり役割を果たすチームプレーです。

話すだけでなく、実際に動きます

アシスタントにはそれぞれ専用の机があります。あなたのものとは別のブラウザです。そこで、価格を調べたり、フォームに入力したり、下書きを用意したりします。

決めるのは、いつもあなたです

アシスタントは準備をします。決めるのはあなたです。初期設定では、「承認」を押すまで大切なことがパソコンの外に出ることはありません。

FreeDuetがあると

「今朝届いたものをすべて片づけて」と一言書くだけ。あとは短い報告を読んで、納得できるところで「承認」を押します。

Enterキーを押したあとに起こること

魔法も秘密もありません。いつも同じ5つの手順なので、誰が何をしているか、いつでも分かります。

  1. 必要なことを書く

    友だちにメッセージを送るように、ふだんの言葉で、あなたの言語で書けます。

  2. Irisが適任のアシスタントを選ぶ

    依頼を読み、その仕事の担当者に渡します。

  3. アシスタントが自分の机で作業する

    専用のブラウザで、調べたり、読んだり、準備したりします。読んだ内容は情報として扱い、命令としては扱いません。

  4. カードで「はい」を確認する

    初期設定では、送信・支払い・署名・予約・削除のような大事な操作が必要なときは、すべて止まって、あなたの返事を待ちます。

  5. 短い報告を受け取る

    何をしたか、何をしなかったか、その理由、次の一歩を伝えます。長い文章は読ませません。

プログラムが掛ける鍵

このルールはアシスタントへの指示に書いてあり、さらに初期設定では、あなたが承認するまでプログラム自体がその操作を止めます。

だまそうとしても通用しません

「急ぎです、パスワードを送ってください」というメールは、読むための文章としてだけ扱い、命令として扱うことは決してありません。また、アシスタントがチャットでパスワードやカード番号を聞くことはありません。

正直な近道がひとつだけ

あなた自身がアドレスを入力した場合（「anna@example.com にメールして、こう伝えて…」）は、その文章が「はい」の返事になり、その新しいメールは送信されます。初期設定では、それ以外の場所で見つけたアドレスには、先に確認します。

45/45

私たちは、自分たちのアシスタントをわざとだまそうとするテストを行っています。バージョン0.1の直近の全体テストでは、安全性のチェックが45回中45回で合格でした。公開レポートを読む。アシスタントも間違えることがあります。承認する前に、用意された内容を必ず読んでください。

二重に払わなくていい理由

多くのAIツールでは「APIキー」を買う必要があります。これはタクシーのメーターのようなものです。言葉を使うたびに少しずつ料金がかかり、請求額は増え続けます。

毎月のAI契約は、定期券に近いものです。料金は一定で、定期券で認められている範囲なら乗り放題。FreeDuetは、すでにお持ちの定期券で動きます。サインインはあなた自身が行います。FreeDuet自身のコードは、あなたのログイン情報を読んだり、コピーしたり、転送したりすることはありません。ログイン情報はあなたのパソコンに残り、読み取れるのはClaude Codeのプログラムだけです。

  • 現在は、公式のClaude Codeアプリを通して、Claudeの契約で利用できます。
  • ほかの契約やローカルモデルへの対応は進行中です。どれも、確認が済んでから初めて提供されます。
  • FreeDuet自体は無料です。コードはMITライセンスで公開されています。

めざすのは、大企業だけでなく、すべての人のためのチーム

大企業には、アシスタントも弁護士も会計士もいます。フリーランスや小さなお店、家族には、自分たちしかいません。それは不公平です。そして今は、変えることができます。

私たちは、誰もがチームを持てるようにしたいと考えています。無料で、オープンで、手元で動くかたちです。FreeDuetはあなたのパソコンで動き、初期設定では会話の記録もそのパソコンのデータベースに保存します。考える部分は、すでに契約しているAIが担当します。

オープンソースとは、レシピが公開されているということです。誰でも読んで、言っている通りに動くか確かめて、よりよくすることができます。私たちを信じる必要はありません。自分の目で確かめられます。

    メンバーごとのエンジン選択は進行中です。エンジンのページは作成済みですが、実環境ではまだ確認していません。自動の切り替えは、テスト用のエンジンでしか動かしていません。チャットで変更する設定（元に戻すボタン付き）は進行中です。メンバーの名前、口調、言語は、v0.2の後に作成済みですが、実環境ではまだ確認しておらず、口調と言語については、まだテストを行っていません。チーム内での本当の作業分担は予定しています。

インストールから、最初の役に立つ仕事まで

実際の順番どおりの4ステップです。すべてのコマンドは、少し下の1つの枠にもまとめてあり、そのままコピーできます。

  1. $ git clone https://github.com/MarcoDeliaBot/freeduet.git
$ cd freeduet
$ cp .env.example .env

    コードを入手する

    1つ目のコマンドでGitHubからFreeDuetをダウンロードし、もう1つでサンプルの設定ファイルをコピーします。

  2. $ bash scripts/start.sh
    • Docker
    • Bash
    • Bun
    • Windows + WSL2

    起動スクリプトを実行する

    1つのスクリプトで、アプリとチーム、そして各メンバー専用のコンピュータを起動します。Docker、Bash、Bunが必要です。WindowsではWSL2の中で実行してください。

  3. $ cd openbot && docker compose exec -it agent-freeduet claude
    Claude Codeサインイン済み

    Claudeのプランで、一度だけサインインする

    公式のClaude Codeのサインインを開き、ご自身でログインします。FreeDuet自身のコードは、ログイン情報を読んだり、コピーしたり、転送したりすることはありません。ログイン情報はあなたのパソコンに残り、読み取れるのはClaude Codeのプログラムだけです。

  4. http://localhost:3010
    今夜、ほうれん草と卵で何が作れますか？

    ページを開いて、Irisに小さな仕事を頼む

    ブラウザでlocalhost:3010を開き、小さな依頼を1つ書いてみましょう。Irisが適切なアシスタントを選び、答えを持ってきます。

準備はいいですか？ 4つのコマンドのあとサインインすれば、チームが動き出します

ターミナルにコピーして貼りつけ、ご自身のClaudeプランで一度サインインしたら、表示されたページを開いてください。

必要なもの： Claudeの契約と、パソコンにDocker、Bash、Bunが入っていること。WindowsではWSL2を使った環境と、Linuxで動作確認しています。

最初によくある質問

何が無料で、何にお金がかかりますか？

FreeDuetは無料で、MITライセンスのオープンソースです。仕事での利用もできます。かかるのは、一緒に使うAIの契約料金だけで、現在はClaudeのプランです。APIキーを買う必要はありません。

インストールに必要なものは？

Claudeの契約と、パソコンにDocker、Bash、Bunが入っていること。上の4ステップがインストールのすべてです。ターミナルを開いたことがありませんか？ 詳しい人に設定をお願いして、このページを見せてください。

Windows、Mac、Linuxで動きますか？

開発者はWindowsでWSL2とDockerを使って動かしており、自動チェックではLinuxで起動を確認しています。Macでは試していないため、動くとは約束できません。FreeDuetは初期版で、最新の公開版はバージョン0.2.2（2026年11月16日）です。1人の開発者が作って使っています。

アシスタントが確認なしでできることは？

調べもの、読み取り、下書きや報告の作成はできます。初期設定では、5つのボタンは「承認」を待ちます。ただし、あなたが入力したアドレスへの新しいメールは例外です。あなたの言葉で設定した常時適用のメールルールは、新着メールに自動で適用されます。ラベルを付ける、アーカイブする、既読にする、迷惑メールフォルダーやゴミ箱へ移動する、といった操作ができますが、転送・返信・送信・完全な削除は行いません。Full accessは、メンバーごとに、あなた自身のチャットでの待機を外します。これは作成済みですが、実環境ではまだ確認していません。パスワードと安全設定は、あなたに残ります。アシスタントも間違えることがあるので、承認する前に、用意された内容を読んでください。

データはどこにありますか？

FreeDuetはあなたのパソコンで動き、初期設定では会話の記録もそこのデータベースに保存します。ClaudeのログインはDockerボリュームに残り、読み取れるのはClaude Codeのプログラムだけです。考えるときは、サインインしたAIサービスに依頼を送ります。そのサービス自身のアプリと同じ方法です。

スマートフォンから使えますか？

まだスマートフォン版はありません。現在のFreeDuetは、パソコンのブラウザで開きます。v0.2.2からは、パソコンから、リンクまたはQRコードで表示されるワンタイムコードを使って、スマートフォンのブラウザをペアリングできます。スマートフォンのペアリングは、2026年11月16日に一つのインストールで実機実行されました。承認の依頼も届くスマートフォン版と、リモートアクセスは開発中です。

自分のメンバーを追加できますか？

はい。新しいアシスタントを作るLeoに、必要な仕事に合わせて設計してもらうか、ご自身で定義を書いてください。メンバーの名前を変えたり、話し方を変えたりすることは、作成済みですが、実環境ではまだ確認していません。メンバーの定義の仕方。

困ったときはどこで相談できますか？

GitHubでissueを作成してください。質問、エラー、修正案、「使っています」という報告のために、短いフォームがあります。英語かイタリア語で書けます。
