Base de données locale et aucune clé API

L'application, la base de données et les navigateurs des membres tournent sur ton propre ordinateur. Elle utilise ton forfait Claude existant, donc il n'y a aucune clé API à acheter. Les moteurs gratuits et locaux sont construits, désactivés par défaut, et pas encore éprouvés avec un vrai modèle.

Démarrage rapide

Quatre étapes pour ta première tâche.

Apporte ton propre forfait Claude, plus Docker, Bash et Bun. Tourne sous Windows avec WSL2 et sous Linux (la CI le démarre sous Linux) ; macOS n'a pas été testé.

  1. 01
    Récupère le code

    Clone FreeDuet depuis GitHub et copie le fichier de réglages d'exemple.

  2. 02
    Lance le script de démarrage

    Démarre l'application, tous les assistants et les navigateurs isolés des membres. Nécessite Docker, Bash et Bun (WSL2 sous Windows).

  3. 03
    Connecte-toi une fois avec ton forfait Claude

    Connecte-toi toi-même à Claude Code officiel. FreeDuet ne copie et ne transmet jamais ta connexion : elle reste en local dans son volume Docker.

  4. 04
    Ouvre localhost:3010 et dis bonjour à Iris

    Écris une petite tâche quotidienne dans ta langue. Iris la confie au bon membre et te demande ton oui là où il faut.

Toutes les commandes · copier et lancer

FreeDuet est gratuit et open source sous licence MIT, y compris pour un usage professionnel. Tu apportes l'abonnement IA mensuel que tu as déjà : aujourd'hui, un forfait Claude via l'application officielle Claude Code. Aucun compteur de clé API à la consommation n'est à acheter. Des moteurs supplémentaires (modèles gratuits ou locaux) peuvent être ajoutés sur la page Moteurs ; ils sont désactivés par défaut, et seule la connexion Claude a répondu à un vrai tour jusqu'ici.

Un abonnement Claude, plus Docker, Bash et Bun sur ton ordinateur. Le mainteneur le fait tourner sous Windows avec WSL2, et la CI le démarre proprement sous Linux. Il n'a pas encore été testé sous macOS. Un installeur à double-clic en un seul fichier est le chantier prioritaire en cours ; les premiers scripts d'installation pour Ubuntu et Windows n'ont pas encore tourné sur une machine vierge.

L'application, la base de données et le navigateur isolé de chaque assistant tournent sur ton ordinateur. Par défaut, tes conversations y restent stockées en local. Pour réfléchir, les demandes sont envoyées au service d'IA auquel tu t'es connecté (ou à tout moteur supplémentaire que tu actives manuellement sur la page Moteurs).

Il peut chercher, lire, vérifier et préparer des brouillons et de courts rapports. Par défaut, Envoyer, Payer, Signer, Réserver et Supprimer s'arrêtent à ta fiche d'approbation : une règle fixe repère les mots, et un modèle relecteur vérifie le reste par rapport à ce que tu as tapé. Exceptions : un tout nouvel e-mail à une adresse que tu saisis toi-même, les règles permanentes de messagerie que tu fixes (étiqueter, archiver, marquer comme lu, déplacer vers Spam ou la Corbeille uniquement), et le Full access si tu l'actives pour un membre. Les assistants peuvent quand même se tromper : lis chaque fiche avant d'approuver.

La révocation d'un jumelage et l'approbation depuis le téléphone ne sont pas encore vérifiées, et l'accès à distance depuis l'extérieur de ton réseau domestique est encore en cours.
