Быстрый старт

Четыре шага до первой задачи.

Нужны твой тариф Claude плюс Docker, Bash и Bun. Работает на Windows через WSL2 и на Linux (CI запускает его на Linux); на macOS не проверялось.

  1. 01
    Скачай код

    Клонируй FreeDuet с GitHub и скопируй файл с примером настроек.

  2. 02
    Запусти стартовый скрипт

    Запускает приложение, всех помощников и изолированные браузеры участников. Нужны Docker, Bash и Bun (на Windows — WSL2).

  3. 03
    Один раз войди со своим тарифом Claude

    Войди в официальный Claude Code сам. FreeDuet никогда не копирует и не передаёт твои данные для входа — они остаются локально, в его томе Docker.

  4. 04
    Открой localhost:3010 и поздоровайся с Iris

    Напиши одну небольшую бытовую задачу на своём языке. Iris передаст её нужному участнику и попросит твоё одобрение там, где оно нужно.

Все команды · скопировать и запустить
$ git clone https://github.com/MarcoDeliaBot/freeduet.git$ cd freeduet && cp .env.example .env$ bash scripts/start.sh # приложение, команда и браузеры$ cd openbot && docker compose exec -it agent-freeduet claude
Затем открой localhost:3010Поздоровайся с Iris и начни первую небольшую задачу.

FreeDuet бесплатен и открыт по лицензии MIT, в том числе для бизнеса. Ты приносишь ежемесячную подписку на ИИ, которая у тебя уже есть — сегодня это тариф Claude через официальное приложение Claude Code. Покупать счётчик оплаты за токены по API-ключу не нужно. Дополнительные движки (бесплатные или локальные модели) можно добавить на странице Engines; они выключены по умолчанию, и пока на настоящий запрос ответил только вход в Claude.

Подписка Claude, а также Docker, Bash и Bun на твоём компьютере. Разработчик запускает это на Windows с WSL2, а CI чисто запускает на Linux. На macOS пока не проверялось. Установщик в один файл, который запускается двойным щелчком, — главная задача в работе; первые стартовые скрипты для Ubuntu и Windows ещё не запускались на чистой машине.

Приложение, база данных и изолированный браузер каждого помощника работают на твоём компьютере. По умолчанию переписка хранится там же. Чтобы думать, запросы уходят в ИИ-сервис, в который ты вошёл (или в любой дополнительный движок, который ты включил вручную на странице Engines).

Он может искать, читать, проверять, готовить черновики и короткие отчёты. По умолчанию Отправить, Оплатить, Подписать, Забронировать и Удалить ждут твоей карточки одобрения: фиксированное правило ищет слова, а модель-проверяющий сверяет остальное с тем, что ты написал. Исключения: совсем новое письмо на адрес, который ты сам вводишь; постоянные почтовые правила, которые ты задал (только ярлык, архив, «прочитано», перенос в Спам или Корзину); и Full access, если ты включил его для участника. Помощники всё равно могут ошибаться, поэтому читай каждую карточку перед одобрением.
