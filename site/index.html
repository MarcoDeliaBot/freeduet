Quick start

Four steps to your first task.

Bring your own Claude plan plus Docker, Bash, and Bun. Runs on Windows with WSL2 and on Linux (CI starts it on Linux); macOS has not been tested.

  1. 01
    Get the code

    Clone FreeDuet from GitHub and copy the example settings file.

  2. 02
    Run the start script

    Starts the app, all assistants, and isolated member browsers. Needs Docker, Bash, and Bun (WSL2 on Windows).

  3. 03
    Sign in once with your Claude plan

    Log into official Claude Code yourself. FreeDuet never copies or forwards your sign-in — it stays locally in its Docker volume.

  4. 04
    Open localhost:3010 & greet Iris

    Write one small everyday task in your language. Iris hands it to the right member and asks for your approval where it is needed.

All commands · copy & run
$ git clone https://github.com/MarcoDeliaBot/freeduet.git$ cd freeduet && cp .env.example .env$ bash scripts/start.sh # app, team & browsers$ cd openbot && docker compose exec -it agent-freeduet claude
Then open localhost:3010Say hello to Iris and start your first small task.

FreeDuet is free and open source under the MIT licence, including for business use. You bring the monthly AI subscription you already have — today a Claude plan through the official Claude Code app. No pay-per-token API key meter to buy. Extra engines (free or local models) can be added on the Engines page; they are off by default, and only the Claude login has answered a real turn so far.

A Claude subscription plus Docker, Bash, and Bun on your computer. The maintainer runs it on Windows with WSL2, and CI starts it cleanly on Linux. It has not yet been tested on macOS. A one-file double-click installer is the top item in progress; the first-step install scripts for Ubuntu and Windows have not yet run on a clean machine.

The app, database, and each assistant's isolated browser run on your own computer. By default your conversations stay stored locally there. To think, requests go to the AI service you signed in to (or any extra engine you manually enable on the Engines page).

It can search, read, check, and prepare drafts and short reports. By default, Send, Pay, Sign, Book, and Delete pause for your approval card: a fixed rule matches the words, and a reviewer model checks the rest against what you typed. Exceptions: a brand-new email to an address you type yourself, standing mail rules you set (label, archive, mark read, move to Spam or the Bin only), and Full access if you switch it on for a member. Assistants can still make mistakes, so read every card before approving.

Yes. Ask Leo in chat to design a brand-new specialist for the exact job you need, or edit a member definition yourself. When a tool is missing, Leo lists its source and licence first and installs nothing without your yes.

v0.2.2 can pair a phone browser from your computer with a one-time code shown as a QR code; this ran once on the maintainer's own installation on 16 November 2026. Revoking a pairing and approving from the phone are not yet checked, and remote access from outside your home network is still in progress.
