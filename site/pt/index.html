Início rápido

Quatro passos até sua primeira tarefa.

Traga o seu plano Claude e também Docker, Bash e Bun. Roda no Windows com WSL2 e no Linux (o CI o inicia no Linux); o macOS não foi testado.

  1. 01
    Baixe o código

    Clone o FreeDuet do GitHub e copie o arquivo de configurações de exemplo.

  2. 02
    Execute o script de início

    Inicia o app, todos os assistentes e os navegadores isolados dos membros. Precisa de Docker, Bash e Bun (WSL2 no Windows).

  3. 03
    Entre uma vez com o seu plano Claude

    Faça login no Claude Code oficial você mesmo. O FreeDuet nunca copia nem encaminha o seu login — ele fica localmente no volume do Docker.

  4. 04
    Abra localhost:3010 e cumprimente a Iris

    Escreva uma pequena tarefa do dia a dia no seu idioma. A Iris a passa ao membro certo e pede o seu sim onde for preciso.

Todos os comandos · copie e rode
$ git clone https://github.com/MarcoDeliaBot/freeduet.git$ cd freeduet && cp .env.example .env$ bash scripts/start.sh # app, equipe e navegadores$ cd openbot && docker compose exec -it agent-freeduet claude

Roteiro completo no GitHub Pergunte ou relate no GitHub

O FreeDuet é grátis e de código aberto sob a licença MIT, inclusive para uso empresarial. Você traz a assinatura mensal de IA que já tem — hoje, um plano Claude pelo app oficial Claude Code. Não há um medidor de chave de API por uso para comprar. Motores extras (modelos gratuitos ou locais) podem ser adicionados na página Motores; eles vêm desligados por padrão, e até agora só o login do Claude respondeu a um turno real.

Uma assinatura Claude e Docker, Bash e Bun no seu computador. O mantenedor roda no Windows com WSL2, e o CI inicia sem problemas no Linux. Ainda não foi testado no macOS. Um instalador de arquivo único com duplo clique é o item principal em andamento; os primeiros scripts de instalação para Ubuntu e Windows ainda não rodaram em uma máquina limpa.

O app, o banco de dados e o navegador isolado de cada assistente rodam no seu computador. Por padrão, as suas conversas ficam guardadas localmente ali. Para pensar, as requisições vão ao serviço de IA em que você entrou (ou a qualquer motor extra que você ative manualmente na página Motores).

Ele pode pesquisar, ler, conferir e preparar rascunhos e relatórios curtos. Por padrão, Enviar, Pagar, Assinar, Reservar e Apagar param no seu cartão de aprovação: uma regra fixa reconhece as palavras, e um modelo revisor confere o restante com o que você digitou. Exceções: um e-mail novo para um endereço que você mesmo digita, regras de e-mail permanentes que você define (só marcar com etiqueta, arquivar, marcar como lido, mover para Spam ou Lixeira) e o Full access, se você o ligar para um membro. Os assistentes ainda podem errar, então leia cada cartão antes de aprovar.

Pode. Peça ao Leo, no chat, para projetar um especialista novo para o trabalho exato que você precisa, ou edite você mesmo a definição de um membro. Quando falta uma ferramenta, o Leo mostra primeiro a origem e a licença, e não instala nada sem o seu sim.

A v0.2.2 pode parear o navegador de um celular a partir do computador, com um código de uso único mostrado como QR code; isso rodou uma vez na instalação do próprio mantenedor, em 16 de novembro de 2026. Revogar um pareamento e aprovar pelo celular ainda não foram verificados, e o acesso remoto de fora da sua rede doméstica continua em andamento.
