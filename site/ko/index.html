팀을 만나 보세요. 각자 맡은 일이 하나씩.

축구팀에 골키퍼가 따로 있는 것과 같은 이유입니다. 하루 종일 한 가지 일만 하면 그 일을 아주 잘하게 됩니다. 아무 마스코트나 눌러서 여섯 가지 애니메이션 표정을 모두 미리 볼 수 있습니다. “지금 공개”는 v0.2.2 릴리스에 들어 있다는 뜻이며, 그중 많은 부분은 아직 실제로 실행하지 않았습니다.

오늘

로컬 데이터베이스와 API 키 없음

앱, 데이터베이스, 멤버의 브라우저는 내 컴퓨터에서 실행됩니다. 이미 가진 Claude 요금제를 쓰므로 사야 할 API 키가 없습니다. 무료 엔진과 로컬 엔진은 만들어졌고 기본값은 꺼짐이며, 실제 모델로는 아직 검증되지 않았습니다.

저희는 일부러 저희 팀을 속여 봅니다. v0.1은 안전 실행 45회 중 45회를 통과했습니다. 가장 최근의 전체 실행은 2026년 11월 22일, 사례 107개(그중 안전 사례 50개)로 진행했고, 기준에 미치지 못했습니다. 채점된 사례 98개 중 88개가 통과했고, 안전 사례는 47개 중 40개가 통과했습니다. 승인하기 전에는 늘 직접 검토하세요.

공개 보고서 보안 규칙

빠른 시작

네 단계면 첫 작업을 시작할 수 있습니다.

직접 가진 Claude 요금제와 함께 Docker, Bash, Bun을 준비하세요. Windows에서는 WSL2로, Linux에서는 실행됩니다(CI가 Linux에서 시작합니다). macOS는 테스트하지 않았습니다.

  1. 01
    코드 받기

    GitHub에서 FreeDuet을 내려받고 예시 설정 파일을 복사합니다.

  2. 02
    시작 스크립트 실행

    앱, 모든 비서, 격리된 멤버 브라우저를 시작합니다. Docker, Bash, Bun이 필요합니다(Windows는 WSL2).

  3. 03
    Claude 요금제로 한 번 로그인

    공식 Claude Code에 직접 로그인하세요. FreeDuet은 로그인 정보를 복사하거나 전달하지 않으며, 정보는 Docker 볼륨 안 내 컴퓨터에 남습니다.

  4. 04
    localhost:3010을 열고 Iris에게 인사

    일상에서 쓰는 작은 일을 내 언어로 한 줄 적어 보세요. Iris가 알맞은 멤버에게 넘기고, 필요한 곳에서는 내 승인을 묻습니다.

전체 명령 · 복사해서 실행
$ git clone https://github.com/MarcoDeliaBot/freeduet.git$ cd freeduet && cp .env.example .env$ bash scripts/start.sh # 앱, 팀, 브라우저$ cd openbot && docker compose exec -it agent-freeduet claude
그다음 localhost:3010을 여세요Iris에게 인사하고 첫 작은 작업을 시작하세요.
전체 안내

자주 묻는 질문

사람들이 가장 먼저 묻는 질문.

쉬운 말로 드리는 답변입니다. 아직 진행 중이거나 실제로 실행하지 않은 것은 그렇게 표시합니다.

GitHub의 전체 로드맵 GitHub에서 질문하거나 신고하기

FreeDuet은 MIT 라이선스에 따라 무료이며 오픈 소스입니다. 업무에 써도 됩니다. 이미 가진 월 AI 구독을 쓰시면 되고, 지금은 공식 Claude Code 앱을 통한 Claude 요금제입니다. 사야 할 토큰별 API 키 요금은 없습니다. 추가 엔진(무료 모델이나 로컬 모델)은 엔진 페이지에서 붙일 수 있으며, 기본값은 꺼져 있고, 지금까지 실제 대화에 답한 것은 Claude 로그인뿐입니다.

Claude 구독과 내 컴퓨터의 Docker, Bash, Bun이 필요합니다. 개발자는 WSL2를 쓰는 Windows에서 실행하고, CI는 Linux에서 깔끔하게 시작되는 것을 확인합니다. macOS에서는 아직 테스트하지 않았습니다. 파일 하나로 된 더블클릭 설치 프로그램이 진행 중인 최우선 항목이며, Ubuntu와 Windows의 첫 설치 스크립트는 아직 깨끗한 컴퓨터에서 실행해 보지 않았습니다.

앱, 데이터베이스, 각 비서의 격리된 브라우저는 내 컴퓨터에서 실행됩니다. 기본적으로 대화 내용도 그곳에 저장됩니다. 생각하는 단계의 요청은 내가 로그인한 AI 서비스로 가며(엔진 페이지에서 직접 켠 추가 엔진이 있다면 그쪽으로도 갑니다).

검색하고, 읽고, 확인하고, 초안과 짧은 보고서를 준비할 수 있습니다. 기본적으로 보내기, 결제, 서명, 예약, 삭제는 내 승인 카드를 기다립니다. 고정 규칙이 단어를 찾고, 검토 모델이 나머지를 내가 입력한 내용과 대조해 봅니다. 예외는 다음과 같습니다. 내가 직접 입력한 주소로 가는 완전히 새로운 이메일, 내가 설정한 상시 메일 규칙(라벨, 보관, 읽음, 스팸이나 휴지통으로 옮기기만 가능), 그리고 켜 둔 멤버의 Full access입니다. 비서도 실수할 수 있으니, 승인하기 전에 카드를 모두 읽어 보세요.

네. 채팅에서 Leo에게 내가 필요한 일에 맞는 새 전문 비서를 설계해 달라고 하거나, 멤버 정의를 직접 고칠 수 있습니다. 도구가 없으면 Leo가 출처와 라이선스를 먼저 보여 주며, 내 승인 없이는 아무것도 설치하지 않습니다.

v0.2.2는 컴퓨터에 QR 코드로 표시되는 일회용 코드로 휴대폰 브라우저를 연결할 수 있습니다. 이 기능은 2026년 11월 16일 개발자 본인의 설치에서 한 번 실행되었습니다. 연결을 해제하거나 휴대폰에서 승인하는 기능은 아직 확인하지 않았고, 집 네트워크 밖에서의 원격 접속은 아직 진행 중입니다.
