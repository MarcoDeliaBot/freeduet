Inicio rápido

Cuatro pasos hasta tu primera tarea.

Trae tu propio plan de Claude más Docker, Bash y Bun. Funciona en Windows con WSL2 y en Linux (el CI lo arranca en Linux); macOS no se ha probado.

  1. 01
    Obtén el código

    Clona FreeDuet desde GitHub y copia el archivo de ajustes de ejemplo.

  2. 02
    Ejecuta el script de inicio

    Arranca la app, todos los asistentes y los navegadores aislados de los miembros. Necesita Docker, Bash y Bun (WSL2 en Windows).

  3. 03
    Inicia sesión una vez con tu plan de Claude

    Entra tú mismo en Claude Code oficial. FreeDuet nunca copia ni reenvía tu inicio de sesión: se queda en local, en su volumen de Docker.

  4. 04
    Abre localhost:3010 y saluda a Iris

    Escribe una tarea pequeña y cotidiana en tu idioma. Iris la pasa al miembro adecuado y pide tu aprobación cuando hace falta.

Todos los comandos · copia y ejecuta
$ git clone https://github.com/MarcoDeliaBot/freeduet.git$ cd freeduet && cp .env.example .env$ bash scripts/start.sh # app, equipo y navegadores$ cd openbot && docker compose exec -it agent-freeduet claude
Después, abre localhost:3010Saluda a Iris y empieza tu primera tarea pequeña.

Hoja de ruta completa en GitHub Pregunta o informa en GitHub

FreeDuet es gratuito y de código abierto bajo la licencia MIT, también para uso empresarial. Tú aportas la suscripción mensual de IA que ya tienes: hoy, un plan de Claude a través de la app oficial Claude Code. No hay que comprar una clave API con medidor por token. Los motores adicionales (modelos gratuitos o locales) se pueden añadir en la página de Motores; están desactivados por defecto, y hasta ahora solo el inicio de sesión de Claude ha respondido a un turno real.

Una suscripción a Claude más Docker, Bash y Bun en tu ordenador. El mantenedor lo ejecuta en Windows con WSL2, y el CI lo arranca sin problemas en Linux. Aún no se ha probado en macOS. Un instalador de un solo archivo con doble clic es el primer elemento en curso; los scripts de instalación del primer paso para Ubuntu y Windows aún no se han ejecutado en una máquina limpia.

La app, la base de datos y el navegador aislado de cada asistente funcionan en tu ordenador. Por defecto, tus conversaciones se quedan guardadas allí, en local. Para pensar, las peticiones van al servicio de IA en el que iniciaste sesión (o a cualquier motor extra que actives a mano en la página de Motores).

Puede buscar, leer, comprobar y preparar borradores e informes breves. Por defecto, Enviar, Pagar, Firmar, Reservar y Borrar se detienen en tu tarjeta de aprobación: una regla fija busca las palabras, y un modelo revisor compara el resto con lo que escribiste. Excepciones: un correo nuevo a una dirección que escribes tú, las reglas de correo permanentes que configures (solo etiquetar, archivar, marcar como leído o mover a Spam o a la Papelera) y Full access si lo activas para un miembro. Los asistentes pueden seguir equivocándose, así que lee cada tarjeta antes de aprobarla.
