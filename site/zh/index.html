公开报告 安全规则

快速开始

四步，完成你的第一项任务。

自备 Claude 套餐，外加 Docker、Bash 和 Bun。可在 Windows（通过 WSL2）和 Linux 上运行（CI 在 Linux 上启动它）；macOS 尚未测试。

  1. 01
    获取代码

    从 GitHub 克隆 FreeDuet，并复制示例设置文件。

  2. 02
    运行启动脚本

    启动应用、所有助理以及独立的成员浏览器。需要 Docker、Bash 和 Bun（Windows 上需要 WSL2）。

  3. 03
    用你的 Claude 套餐登录一次

    请自行登录官方的 Claude Code。FreeDuet 从不复制或转发你的登录信息，它只留在 Docker 卷中的本地。

  4. 04
    打开 localhost:3010，向 Iris 打个招呼

    用你的语言写一件简单的日常小事。Iris 会把它交给合适的成员，并在需要时请你批准。

全部命令 · 复制并运行
$ git clone https://github.com/MarcoDeliaBot/freeduet.git$ cd freeduet && cp .env.example .env$ bash scripts/start.sh # 应用、团队与浏览器$ cd openbot && docker compose exec -it agent-freeduet claude
然后打开 localhost:3010向 Iris 打声招呼，开始你的第一个小任务。

FreeDuet 是免费的开源软件，采用 MIT 许可证，包括商业用途。你只需自带已经订阅的 AI 月费服务——目前是通过官方 Claude Code 应用使用的 Claude 套餐。无需购买按 token 计费的 API 密钥。额外的引擎（免费或本地模型）可以在引擎页面添加；它们默认关闭，到目前为止只有 Claude 登录完成过真实的一次对话。

一个 Claude 订阅，外加你电脑上的 Docker、Bash 和 Bun。维护者在 Windows 上通过 WSL2 运行它，CI 在 Linux 上也能顺利启动。尚未在 macOS 上测试。一键双击安装程序是正在进行中的首要事项；Ubuntu 和 Windows 的第一步安装脚本尚未在干净的机器上运行过。

应用、数据库以及每位助理各自的独立浏览器都运行在你自己的电脑上。默认情况下，你的对话会保存在那里的本地。需要思考时，请求会发送到你登录的 AI 服务（或你在引擎页面手动启用的任何额外引擎）。

它可以搜索、阅读、核对，并准备草稿和简短报告。默认情况下，发送、付款、签署、预订和删除会暂停，等你的批准卡：固定规则匹配关键词，审核模型再把其余部分与你的输入对照。例外包括：发给你自己输入地址的全新邮件；你设置的常规邮件规则（仅限标签、归档、标为已读，或移到垃圾箱或回收站）；以及你为某位成员开启的 Full access。助理仍可能出错，所以批准前请阅读每一张卡片。
