FreeDuet

属于你自己的 AI 助理团队。

FreeDuet 运行在你的电脑上。有人负责你的邮件，有人帮你读合同，有人帮你订餐厅。你只管说需要什么，他们来干活，而且默认情况下，未经你同意，绝不发送、付款或删除任何东西。

在 GitHub 上获取 FreeDuet 看看它怎么运作
  • 免费，开源
  • 无需购买 API 密钥
  • 运行在你自己的电脑上

事情太多，却只有一个你？

邮件、发票、预订、合同，还有上周答应了却没回的那封邮件。一个脑袋，两只手，一百件事。

FreeDuet 就像住在你电脑里的一间小办公室，里面的助理各有专长，每人只做好一件事。你只需要和 Iris 说话，她是团队的负责人，会让大家都动起来。

是一支由多位助理组成的团队

聊天机器人是一位聪明的朋友，回答你的问题。FreeDuet 则是一个真正分工合作的团队，每个人都实实在在地出力。

它会动手做事，而不只是说说

每位助理都有自己的“办公桌”：一个与你的浏览器分开的独立浏览器。在那里，它可以查价格、填表格、准备草稿。

你永远是老板

助理负责准备，你来决定。默认情况下，发送、付款或删除要等你按下“批准”才会进行。

没有 FreeDuet 时

你打开邮箱，读四十封邮件，翻找那张发票，比较三个航班，写回信，还忘了买生日礼物。

有了 FreeDuet

你只写一句话：“把今天早上收到的事都处理一下。”然后读一份简短的报告，同意的地方按下“批准”。

认识团队成员，每人只负责一件事。

你按下回车之后发生了什么

没有魔法，也没有秘密。永远是同样的五步，所以你始终清楚谁在做什么。

  1. 你写下需要什么

    用你自己的话、你自己的语言，就像给朋友发消息一样。

  2. Iris 挑选合适的助理

    她读懂你的请求，交给负责那类工作的专家。

  3. 助理在自己的“办公桌”上工作

    它用自己的浏览器搜索、阅读和准备。它被要求把读到的内容当作信息，绝不当作命令。

  4. 一张卡片等你同意

    默认情况下，如果工作涉及重要的大按钮（发送、付款、签署、预订、删除），一切都会停下来，等你同意。

  5. 你收到一份简短的报告

    做了什么，没做什么以及原因，下一步是什么。没有大段大段的文字。

是一把由程序自己落下的锁

规则写在助理的指令里，默认情况下，程序本身也会拦住这个操作，直到你批准。它对付款、密码和安全设置的检查识别本站十二种语言中的词；用其他方式表述的付款仍可能漏过。

花招没有用

一封写着“把密码发给我，很急”的邮件只是要读的文字，助理被要求绝不把它当命令执行。它们也被要求绝不在聊天里向你要密码或银行卡号，而且成员的电脑会拒绝在密码、验证码或银行卡输入框里打字。没有标记的输入框可能漏过这一拒绝。

一个坦诚的捷径

如果你自己输入了地址（“给 anna@example.com 发邮件，告诉她……”），你写下的这句话就是你的同意，这封新邮件就会发出。默认情况下，在其他任何地方找到的地址都会先问你。

为什么你不用付两次钱

大多数 AI 工具要你购买一个“API 密钥”。它就像出租车计价器：每说一个字就跳一点钱，账单越滚越高。

按月订阅的 AI 服务更像公交月票：一个价格，在月票允许的范围内随便坐。FreeDuet 用的就是你已经有的这张月票。登录由你自己完成。FreeDuet 自身的代码从不读取、复制或转发你的登录信息：它留在你的电脑上，放在只有 Claude Code 程序会读取的地方。

  • 目前支持 Claude 订阅，通过官方的 Claude Code 应用使用。
  • 更多订阅仍在进行中。本地模型、OpenRouter 的免费模型和你自己的 FreeLLMAPI 路由器已经做好，可以在引擎页面上添加。除非你自己选择该顺序，否则它们都不会排在成员的第一位；只有团队的测试在某个模型上通过后，才算该模型受支持。
  • FreeDuet 本身不收费：代码以 MIT 许可证公开。

我们的目标：让每个人都有团队，而不只是大公司

大公司有助理、律师和会计。自由职业者、小店铺或普通家庭，却只有……自己。这不公平，而现在，这种情况可以改变。

我们希望每个人都能拥有一支团队：免费、开放，就在自己家里。FreeDuet 运行在你自己的电脑上，默认情况下对话记录也保存在这台电脑的数据库里。负责思考的，是你已经订阅的那个 AI。

开源的意思是“配方”公开。任何人都可以阅读，确认它说到做到，还能把它改得更好。你不必只靠信任我们，你可以亲自去看。

大家最先会问的问题

什么是免费的，我要为什么付费？

FreeDuet 是免费的开源软件，采用 MIT 许可证，也可用于商业用途。你只需为与它搭配使用的 AI 订阅付费，目前是 Claude 套餐。你还可以在引擎页面添加免费模型，但它们的提供方可能会保留发送给它们的内容。无需购买 API 密钥。

安装需要准备什么？

一个 Claude 订阅，以及电脑上的 Docker、Bash 和 Bun。上面的四个步骤就是全部安装过程。从没打开过终端？请懂技术的朋友帮你装好，把这个页面给他看就行。

能在 Windows、Mac 和 Linux 上用吗？

维护者在 Windows（配合 WSL2 和 Docker）上使用它，我们的自动检查会在 Linux 上启动它。它没有在 Mac 上测试过，所以我们不能保证能在那里运行。FreeDuet 是早期版本，由一位维护者开发并使用；最新的已发布版本是 0.2.2（2026年11月16日）。

助理不用问我就能做什么？

它可以查资料、阅读，并准备草稿和报告。默认情况下，五个按钮都要等你按下“批准”，只有发给你亲自输入地址的新邮件例外。你用自己的话设定的持久邮件规则会自动作用于新邮件：可以打标签、归档、标记为已读，或移到垃圾邮件或回收站。它从不转发、回复、发送，也从不永久删除。Full access 按成员单独开启，在你自己的对话中取消等待；它已经做好，但还没在真实环境中运行。单纯的 Full access 也会取消付款的等待；“不含付款”则不会。密码和安全设置仍归你，但检查只识别本站十二种语言中的词，用其他方式表述或使用其他字母体系中形似字符的内容仍可能漏过。命令或脚本只有在设置了自动审核员时才会被检查。助理仍可能出错，请先看过它准备的内容再批准。

我的数据在哪里？

FreeDuet 运行在你的电脑上，默认情况下对话记录保存在那里的数据库中。你的 Claude 登录信息留在一个只有 Claude Code 程序会读取的 Docker 卷里。思考时，助理会把你的请求发给你已登录的 AI 服务，就和该服务自己的应用一样。如果你在引擎页面添加引擎，比如免费的云端模型、OpenRouter 或你自己的 FreeLLMAPI 路由器，该成员的消息也会发送给它，它可能会保留这些消息。

能在手机上用吗？

还不是手机版。目前 FreeDuet 在你电脑的浏览器里打开。从 v0.2.2 起，可以在电脑上用链接或二维码显示的一次性代码，把手机浏览器与它配对；手机配对已于2026年11月16日在一次安装上真实运行。手机版（也能在手机上收到需要你批准的请求）和远程访问仍在进行中。

我能添加自己的团队成员吗？

可以。你可以请专门打造新助理的 Leo 为你需要的工作设计一位，也可以自己编写它的定义。给成员改名、换说话方式，已经做好，但还没在真实环境中运行。成员是如何定义的。
