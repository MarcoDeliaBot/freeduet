# Upstream touches

FreeDuet is a thin fork of [OpenDuet](https://github.com/CopilotKit/OpenDuet). Its own code lives in `openbot/examples/freeduet/`, `openbot/agent-freeduet/`, `openbot/server/src/freeduet/` and `openbot/app/src/freeduet/`. Every change to a file that came from upstream is listed here with its reason, so merging upstream stays easy ([EXECUTOR_BRIEF.md](EXECUTOR_BRIEF.md), rule 2).

"Upstream?" says whether the change is worth proposing to CopilotKit. Nothing is proposed without the maintainer's approval.

## Not changed, on purpose

- `openbot/server/src/config.ts` and `openbot/scripts/generate-app-config.ts` keep OpenDuet's default package. FreeDuet sets `TENANT_PACKAGE_DIR` in `.env`, and upstream tests expect the upstream default.
- `openbot/server/src/agents/plan-model.ts` is untouched: the token never reaches it.
- `openbot/server/src/tenant-package.ts`, `channels/routes.ts`, `routines/store.ts` and `app.ts` are untouched by the team wiring: the hub grants run after the sync in their own transaction, and each person's conversations and routine go through the channel and routine stores' existing calls. Package channels stay member-less (`db/schema/core.ts`), so nobody sees anybody else's conversations.
- `openbot/desktop/` still offers a Claude plan sign-in. FreeDuet does not ship the desktop app; before it ever does, that option must go too.
- The Helm chart (`openbot/charts/`) still defaults to OpenDuet's package; it is not part of FreeDuet's install yet.
- Found while fixing hand-offs, not changed: `CloningRemoteAgent.clone()` (`openbot/toolkit/src/copilotkit/agents.ts`) builds a fresh agent with only the middleware its constructor attaches, so the personal-memory and channel middleware added later (`copilot.ts` `buildAgents`, `openduet/run-channel.ts`) never reach a remote Bot in a browser chat, which runs on a clone; a hop runs on the uncloned agent and gets both, in front of the standing role. agent-freeduet now reads the role wherever it is. Worth reporting upstream.
- Found, not changed: the safety floor (`approvals/policy.ts`, `SAFETY_REQUIREMENTS`) matches words in a hand-off's free-text task, so "draft a payment reminder" sent to Penny is handed to the person as if it were a payment. Left as it is: weakening it is not FreeDuet's call, and the receiving member's real sends and payments are gated again in its own run.
